## 5. 壓克力工序成本模型（修正版，逆向自 v1.5.0 / v1.5.2 / v1.5.6，每條附儲存格）

> 儲存格座標以 `主产品` 分頁為準（v1.5.2 柯氏檔的 `5万`/`2.1万`/`5000` 分頁列位完全相同）。證據格式：檔名 / 分頁 / 儲存格。
> 衝突處理原則：以「儲存格證據 + 較新版本（v1.5.6 / 較晚存檔）」為現值；舊值只留在 golden case 的 `settings_snapshot`。

### 5.0 引擎三條鐵則

1. **引擎「照抄」Excel 行為，包含已知瑕疵**（5.6 列出）。每個瑕疵做成 `quote_settings` 旗標，預設值 = Excel 現況；否則 golden case 對不上。
2. **所有常數都不寫死在引擎裡**，全部來自 `quote_price_items` / `quote_settings`，且帶 `effective_from` 與來源檔。同一格在不同檔案值不同（例如外形刀單價 12 vs 27）就是「後台參數 + 生效日」，不是 bug。
3. **分母永遠是訂單數 Q**（`E9 = L3`），不是投產數；報廢率一律在最後一步乘上去（`G 欄 = F 欄 × (1 + L5/100)`）。

### 5.2 拼板 N（`计算器` 分頁）

```
套版尺寸 W × H  ← 掛在板材 attrs，不是全域「留邊」推導
   300×400 板 → 29 × 39      （计算器!B5 = 29、B6 = 39，直接手填）
   330×440 板 → 31.6 × 42.6  （BA26090701 ANDY / 计算器 / B5 = 31.6、B6 = 42.6，每邊 7mm 不是 5mm）
間距 g = 计算器!B7 / 10 = 0.4 cm（H5 = B7/10）
邊距 m = 计算器!B8 / 10 = 0    （H6 = B8/10；H7 = B5 − 2×H6、H8 = B6 − 2×H6）
fit(w, h) = MAX(0, INT((H7 + g)/(w + g))) × MAX(0, INT((H8 + g)/(h + g)))   ← I5 × I6 = I7
N = MAX( fit(a, b), fit(b, a) )                                              ← I9 = MAX(I7, J7)；E5 = IF(B9=矩形, E9, E13)
```
驗證：5×5 → 35（_报价模板_v1.5.6 / 计算器 / E5）、8×10.2 → 9（C款 / 计算器 / E5）、7×7 → 15（登山沟 / 计算器 / E5）、10×10 於 31.6×42.6 → 12（ANDY / 计算器 / E5）。
- `计算器!B9 = 圆形` 走 `E13 / K9` 蜂巢排法，MVP 不做，前台以「手動覆寫 N」代替。
- v1.5.5 多物件排版計算器（`计算器!A19:D25`，含 0.85 面積利用率）沒有任何主表引用，不進引擎。
- **第二板材的 `N2` 不走計算器**：登山沟 `C10 = E9/66` 的 66 是手打；品項設定要能直接給 `N2`。

### 5.3 五段成本（每段：金額 D → ÷Q = F → ×(1 + s/100) = G）

證據：`F9 = D13/E9`、`G9 = F9*(1+L5/100)`；`F17 = D22/E17`、`G17`；`F26 = D31/E9`、`G26`；`F35/G35`、`F44/G44`；`F53 = D64/E9`、`G53`；`F68 = D79/E9`、`G68`（三檔相同）。

**① 材料（`A9:D13`）**
```

主板金額   D9  = 板價 × C9                                          ← B9 = XLOOKUP(A9, 价格表!A:A, B:B)
第二板盤數 C10 = 模板預設 ROUNDUP(Q/N,0)×sides_a（同主板 N）      ← _报价模板_v1.5.6 / C10
                 登山沟特例 = Q / N2，不進位（N2=66）                ← BA26082304 / 主产品 / C10 = E9/66 → 15.1515
第二板金額 D10 = 板價2 × C10                                        ← B10 XLOOKUP；A10 空白時 B10 = 0

                 7151/金谷田:     ROUNDUP(Q/N,0) × sides_p           ← v1.5.6 / C11 = ROUNDUP(E9/H9,0)*IF(L9=双面,2,1)

PET 金額   D11 = PET價 × C11                                        ← B11 XLOOKUP（680×460 覆膜 1.73；310×420 0.7；340×480 0.88）

### 5.4 彙總
```
