# 常平訂單資料區改為擁有者限定＋帶出權威單號(2026-09-14)

## 公告欄白話版

> 「常平訂單資料區」改成**只有指定帳號看得到**，其他人（包含其他管理員）首頁不會出現這張卡片，
> 直接輸入網址也會被擋。
> 列表的單號改用 ARGO 採購單的真實單號：**採購單號 PO** 會顯示對到的採購行（含序號），
> **來源單 SO** 顯示 ARGO 的來源訂單；常平工作表原本寫的號碼（可能是作廢前舊號或夾雜文字）移到滑鼠提示。

## 技術版

### 權限
- 新增 `lib/changpingShipOwner.ts`：`guardChangpingShipOwner()` 以 email 白名單守門，
  **不採用 `guardPermission`**——後者會讓任何 `is_admin` 自動通過，不符「只有我看得到」的需求。
- 名單走環境變數 `CHANGPING_SHIP_OWNERS`（逗號分隔），未設時預設 `s9323162@gmail.com`。
- 非擁有者一律回 **404**（不是 403），不洩漏此功能存在。
- 首頁卡片改為「非擁有者不渲染」，不再只是變灰。
- 團隊管理移除 `changping_ship` 權限鍵（已不生效，留著會誤導）。

### 單號
- `app/api/changping-ship/list/route.ts` 以 `matched_lines` 回查 `erp_pj_sync`，
  每列補上 `po_line`（`POC…#序`，多行以逗號併列）與 `so_erp`（`SO_PROJECT_ID`）。
- 為什麼不用工作表原文：實測 4,268 筆中 **2,668 筆的 SO 欄夾雜註記**
  （例：`RO26011240/常平/PR26011511`）；PO 也可能是作廢前的舊單號
  （例：POC2026071601 作廢後重開為 071603）。
- 頁面兩欄改顯示權威值，工作表原文放 `title` 提示；PO 與工作表不一致時額外標示 `(表:…)`。
- 查詢框同時搜新舊兩種單號。

### 驗證
- `npx tsc --noEmit` 0 errors
