## 為什麼重寫而不是複製

生產版表單 691 行，一半以上是業務美編用不到的機制（MOT 自動帶單、QR Code 手機拍照、LINE 通知文案）。複本會拖著這些包袱一起維護；全新實作 320 行，之後要加減欄位都在這一支動，跟生產版互不影響。
