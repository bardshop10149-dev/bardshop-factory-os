## 做了什麼

### 1. 新增 `lib/core/`（全站單一實作）

| 模組 | 收掉的重複 |
|---|---|
| `lib/core/csv.ts` — `csvCell` / `csvCellQuoted` / `buildCsv` / `downloadCsv` | 6 個具名 CSV 函式（4 種名字）＋ 15 處 inline 引號拼接，散在 20 個檔案 |
| `lib/core/date.ts` — `todayLocalYmd` / `todayIsoDateInput` / `toIsoDateInput` / `taipeiYmd` / `formatYmdSlash` / `normDate` / `parseYmd` / `clampDueDate` | `normDate`×3、`fmtDate`×7、`todayStr`×3、`getTodayDateInput`×3、`taipeiDateStr`×2、`toDateInputValue`×2、`parseYmd`/`clampDueDate`×2 |
| `lib/core/array.ts` — `chunk` | 4 份逐字相同的 `chunk<T>` |

遷移原則：**只合併「逐字相同或語意已逐一比對過」的實作**；每個呼叫端保留原本的引號模式（一律加引號／必要時加引號），輸出位元組不變。`moExportShared.formatDate` 改為指向 `lib/core/date`，名字保留給既有呼叫端。

`ng-order-export` 原本自己重打了 4 個 `moExportShared` 早已 export 的函式（`formatDate`、`getNextBusinessDay`、`parseSoDateDigits`、`truncateByByteLength`），改為直接 import；`group-order-export` 同理。

### 2. 兩處輕微行為修正（都是往正確方向）

- `sara/process-gen` 的 CSV 引號規則原本漏判 `\r`，改用共用版後含 `\r` 的儲存格也會正確加引號。
- 幾處 `String(v)` 直接轉字串的匯出，null 儲存格原本會輸出字面 `"null"`，改為空字串。

### 3. 刻意**沒**合併的（語意不同，合了會出事）

- `daily-order-sheet` 的 `encodeTsvCell`：那是 **TSV**（tab 分隔），引號規則本來就不該含逗號——健檢報告誤判為 bug，特此更正。
- `api/cron/auto-doc-creation` 的 `parseYmd`：比手動頁嚴格（不吃 `YYYYMMDD`、帶時間的日期會判 null 而 clamp 到開立日＋1）。它每天 17:10 在寫 ARGO 單，**要不要對齊手動頁請 Snow 決定**，本次不動。
- `api/design/daily-sheet` 的 `taipeiDateStr`：名字叫台北、實作卻是 UTC，與另兩份 Intl 版不等價，不合併。
- `lib/erpSyncReconcile` 的 `chunk`：空陣列回 `[[]]`，是刻意讓對帳至少跑一輪，保留。

### 4. route 匯出守衛（防第四次踩雷）

`app/api/**/route.ts` 只能匯出 HTTP method 與路由設定；多匯出一個常數，turbopack 不擋、Vercel 照常部署，但 `next build --webpack` 整個失敗。2026-08/09 已連續踩三次（exchange-csv、order-sketch、本次的 schedule-confirm/notes）。

- 新增 `scripts/check-route-exports.mjs`，接進 `npm run build` 最前面——Vercel 打包前就會以清楚訊息擋下，也可手動 `npm run lint:routes`。
- 掛進 `.githooks/pre-push`。**注意**：這個 hook 檔存在已久（含「禁止直接 push main」），但每台機器需要 `git config core.hooksPath .githooks` 才會生效，目前本機**沒有設定**——這是近 30 天 main 有 105 個直接 commit 的原因之一。

### 5. 順手

- 拆除 `schedule-confirm/notes/route.ts` 的 `export const NOTES_TABLE`（第三顆地雷，9/11 才進 main）。
- `app/layout.tsx` 網站標題 `Create Next App` → `BARDSHOP EIP`。
